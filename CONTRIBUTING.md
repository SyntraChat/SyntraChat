# Contributing

Read [organization standards](https://github.com/SyntraChat/.github/blob/main/CONTRIBUTING.md),
[development](docs/DEVELOPMENT.md) and [threat model](docs/THREAT_MODEL.md).
Make focused, tested commits and report real platform evidence. A feature must not be
marked complete from a placeholder, login-page screenshot or mocked native response.
Never commit profile directories, passwords, tokens or signing private keys.
