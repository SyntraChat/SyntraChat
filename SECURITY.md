# Security

This preview is not approved for production credentials. Remote views have no Tauri
capabilities; no credential extraction, scripts or extensions are injected into services.
The local profile remains sensitive OS WebView data and should not be uploaded in reports.

Follow the [private reporting policy](https://github.com/SyntraChat/.github/blob/main/SECURITY.md).
Private GitHub vulnerability reporting must be enabled by repository administrators before
release. No security SLA or contact address has been designated.
